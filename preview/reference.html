Troubleshooting

SymptomFix
The first Deploy to GitHub Pages run failsExpected on a brand-new copy: the workflow starts before Pages is switched on. Set Settings → Pages → Source to GitHub Actions and run the workflow again (Chapter 1, step 1.4).
The deploy workflow is skipped in the starter repositoryBy design. The is_template condition keeps it quiet in the template and lets it run in every repository created from it.
gh extension install github/gh-aw fails with HTTP 403: Resource protected by organization SAML enforcementThe github organization, which publishes gh-aw, enforces SAML single sign-on, so only its members see this. Use the one-paste install in step 2.3: it falls back to gh-aw's official install script, which downloads the release without your token. Outside a codespace you can also authorize the token with the printed link.
The Copy button does nothingYour browser blocked clipboard access. The button then selects the text: press Ctrl+C.
A Your terminal command fails with HTTP 403 in the codespaceThe codespace's built-in token cannot change settings or read security alerts. Sign in with your own account (how) or use the clicks in the step.
Copilot CLI ignores mouse clicks in approval menusUse the arrow keys and Enter. Esc cancels the current request.
GraphQL: Could not resolve team with slug '@.github/copilot-instructions.md'The command was pasted at the Copilot CLI prompt. There, @ starts a file reference, so @copilot became a file path. Nothing changed. Run gh pr edit feature/careers-page --add-reviewer @copilot in the bash terminal, or choose Copilot under Reviewers (step 4.1).
Issues called Title and Description appearedThe two blocks in step 2.10 are two fields of one issue. Close the extra issues and create one issue: block 1 in the Title field, block 2 in the Description field.
The Careers pull request was merged before Copilot reviewed itChapter 4 needs an open pull request. If GitHub still has the old branch, select Delete branch on the merged pull request. Then ask Copilot CLI to create feature/careers-page again from main with a small follow-up change (for example, two more open roles), push it and open a pull request, and run Chapter 4 on it.
The CLI says an administrator replaced your modelA managed policy decides which models you can use. Carry on with the model it chose, or ask your administrator.
The agentic workflow fails to authenticate the Copilot engineOn a repository without a COPILOT_GITHUB_TOKEN secret, add copilot-requests: write under permissions and recompile (Chapter 2, step 2.9).
The agentic workflow sits in QueuedIn the real run it waited a few minutes for a runner. Give it time before re-running.
Actions warns that actions target Node.js 20The starter pins older action versions on purpose. Dependabot version updates fix it in Chapter 6.
The codespace stoppedCodespaces stop after a period of inactivity. Restart from Code → Codespaces; your files are kept.
Anyone can trigger the triage agentCopilot generated roles: all. Remove it to restore gh-aw's default role check, and consider an AI credits cap (Chapter 2, developer mode).
A command I typed in the codespace turned into a Copilot Chat requestVS Code's Chat panel had the focus. Select Skip, close the panel and click inside the terminal before typing (Chapter 2, step 2.1).
The frontmatter check in step 2.8 prints only ---Use the current command in step 2.8, which prints the lines between the two --- separators.
The push says GitHub found vulnerabilities right after Dependabot's fix mergedThe count catches up a few minutes after the merge. Check Security and quality → Dependabot instead (Chapter 6, step 6.4).
Dependabot proposes ejs 7 in the npm groupA major upgrade from the weekly version updates. Leave it open and review it on its own (Chapter 6, step 6.5).
gh workflow disable returns HTTP 403 in the codespaceThe codespace's token cannot change workflows. Use Actions → Issue triage → … → Disable workflow, or your own sign-in (Clean-up).
gh auth login says the device code has expiredThe one-time code is valid for 15 minutes. Run gh auth login again for a new code.

Facilitator notes

  • Timing: about 3.5 hours hands-on: Chapter 1 20 min, Chapter 2 45 min, Chapter 3 30 min, Chapter 4 25 min, Chapter 5 35 min, Chapter 6 30 min, Chapter 7 20 min.
  • Accounts: check before the workshop that every participant has a Copilot plan that includes Copilot CLI and code review, and that Codespaces is allowed for their account or organisation.
  • Cost awareness: the issue-triage run in the real run used about 13 GitHub AI Credits. Copilot Fusion, Copilot code review and AI scan also use AI credits; code scanning, secret scanning, push protection and Dependabot are free on public repositories.
  • Roles: one participant can play every role, or split the room: one person files Lina's issue, one plays Raka and reviews the guardrails.
  • Public by design: everything uses fictional Contoso data. Never use real customer names or secrets in the workshop repository.

Clean-up

  1. Stop or delete the codespace: Code → Codespaces → … → Stop codespace or Delete, or do it at github.com/codespaces.
  2. Disable the agentic workflow if you keep the repository public: Actions → Issue triage → … → Disable workflow.
  3. Keep or archive the repository as your reference.

Or from your terminal:

>_Your terminal (GitHub CLI)
gh workflow disable issue-triage.lock.yml

Disables the triage agent. The codespace's token cannot change workflows (HTTP 403), so use your own sign-in, or click Actions → Issue triage → … → Disable workflow.

>_Bash terminalnot Copilot CLI
gh codespace stop

Works in the bash terminal too: choose the codespace, and the browser editor disconnects as it stops. You can also stop or delete it at github.com/codespaces.
