Before you start

You needWhy
A GitHub accountEverything runs in your own public repository. Public repositories get GitHub Pages, CodeQL code scanning, secret scanning, push protection and Dependabot at no cost.
A GitHub Copilot planCopilot CLI, Copilot Fusion and Copilot code review need a Copilot plan (Copilot Free does not include code review). Copilot usage is billed in GitHub AI Credits.
GitHub CodespacesPersonal accounts get a monthly free allowance (120 core-hours on GitHub Free, enough for about 60 hours on a 2-core machine). Stop the codespace when you finish.
A modern browserNo local installs: the codespace provides Node.js 22 and the GitHub CLI.
Copy and paste. Every step you type has a dark command block with a Copy button, and purple blocks hold the Copilot prompts. Dark blocks run in the bash terminal and purple blocks in Copilot CLI; never paste a command into Copilot CLI. All of them are also on one page: the command sheet.
Workshop assets. Starter template: contoso-company-profile-starter. The repository from the real run: contoso-company-profile. The live result: https://ibranibeny.github.io/contoso-company-profile/. Every chapter was then tested end to end in a fresh repository made from the template, contoso-company-profile-qa: see the test run.
Honest by design. The deck is a product overview; this guide is grounded in GitHub Docs and the GitHub Changelog as of 12 November 2026. Where they differ from the deck (for example, Copilot Projects is in public preview), the overview says so and links the source.

The agentic SDLC you will run

Every chapter is one stage of the same loop. Agents do the repetitive work at each stage; you stay in control of what gets merged and shipped.

Story mode and developer mode

Story mode (default)

Scenes, click-by-click steps, annotated screenshots and copy-ready commands. Ideal for presenters, product owners and anyone new to GitHub.

Developer mode

Switch it on in the top bar to reveal generated files, YAML, permissions and what happens under the hood. Your choice is remembered; add ?mode=dev to a link to share it.

Developer mode

Developer mode is on. Purple panels like this one hold file contents, configuration and internals. Turn the switch off to hide them again.
