Threat detectionGenerated detection jobInjected or malicious output landing
Sanitised outputSafe-output processingLeaking details such as e-mail addresses
No extra networknetwork.allowed: []Calls to arbitrary endpoints

Before real use: remove roles: all, so only trusted roles can start a run.

Contoso Agent-Native Engineering Workshop8 / 16
The agent job never holds write access. Separate jobs check its output and apply only the labels and the one comment it was allowed. Copilot generated roles: all, which lets anyone who opens an issue on a public repository start a run that spends AI credits; remove it before real use.
