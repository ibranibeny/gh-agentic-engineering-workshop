How we tested

  • One public repository made from the template with the step 1.1 command, and one codespace on main.
  • Toolchain in the codespace: Node.js 22.23.4, GitHub CLI 2.103.3, gh-aw 1.2.2 and Copilot CLI 1.0.109.
  • Click paths followed as written. Commands for the bash terminal and the Copilot prompts were entered exactly as published.
  • Optional Your terminal alternatives to click paths were not run, except where listed: the click paths they replace were all run.
  • After the run, every changed command was checked for syntax, and the new frontmatter check was run against the committed workflow file.
