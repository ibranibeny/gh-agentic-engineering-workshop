# Contoso Agent-Native Engineering Workshop

A story-driven, hands-on workshop guide: build, review, secure and ship the Contoso company profile with
GitHub Agentic Workflows, Copilot Fusion, Copilot code review, CodeQL and Copilot Autofix, secret scanning,
Dependabot and GitHub Advanced Security.
