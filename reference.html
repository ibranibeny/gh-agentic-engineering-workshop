Command cheat sheet

All commands run in the codespace terminal unless noted. Story mode readers can do every step in the browser instead.

Chapter 1 · Create the repository from the template

gh repo create contoso-company-profile --public \
  --template ibranibeny/contoso-company-profile-starter --clone

Chapter 1 · Publish GitHub Pages with GitHub Actions

gh api -X POST repos/{owner}/contoso-company-profile/pages -f build_type=workflow
gh workflow run deploy-pages.yml
gh run watch

Chapter 2 · Open a codespace on main

gh codespace create -R <your-account>/contoso-company-profile -b main

Chapter 2 · Build, test and preview the site

npm test
npm run build && npm run serve   # port 8080

Chapter 2 · Install GitHub Agentic Workflows

gh extension install github/gh-aw
# fallback (official install script):
curl -sL https://raw.githubusercontent.com/github/gh-aw/main/install-gh-aw.sh | bash
gh aw version

Chapter 2 · Initialise and compile agentic workflows

gh aw init
gh aw compile

Chapter 2 · Install and start the Copilot CLI

npm install -g @github/copilot
copilot

Chapter 3 · Use Copilot Fusion

/model fusion            # inside a session
copilot --model fusion   # new session

Clean-up · Stop the codespace when you finish

gh codespace stop

Troubleshooting

SymptomFix
The first Deploy to GitHub Pages run failsExpected on a brand-new copy: the workflow starts before Pages is switched on. Set Settings → Pages → Source to GitHub Actions and run the workflow again (Chapter 1, step 1.4).
The deploy workflow is skipped in the starter repositoryBy design. The is_template condition keeps it quiet in the template and lets it run in every repository created from it.
gh extension install github/gh-aw fails with HTTP 403 and an SSO linkYour GitHub CLI token is not authorised for an organisation that enforces SAML single sign-on. Authorise it with the printed link, or install with the official script in the cheat sheet.
Copilot CLI ignores mouse clicks in approval menusUse the arrow keys and Enter. Esc cancels the current request.
The CLI says an administrator replaced your modelA managed policy decides which models you can use. Carry on with the model it chose, or ask your administrator.
The agentic workflow fails to authenticate the Copilot engineOn a repository without a COPILOT_GITHUB_TOKEN secret, add copilot-requests: write under permissions and recompile (Chapter 2, step 2.9).
The agentic workflow sits in QueuedIn the real run it waited a few minutes for a runner. Give it time before re-running.
Actions warns that actions target Node.js 20The starter pins older action versions on purpose. Dependabot version updates fix it in Chapter 6.
The codespace stoppedCodespaces stop after a period of inactivity. Restart from Code → Codespaces; your files are kept.
Anyone can trigger the triage agentCopilot generated roles: all. Remove it to restore gh-aw's default role check, and consider an AI credits cap (Chapter 2, developer mode).

Facilitator notes

  • Timing: about 3 hours hands-on: Chapter 1 20 min, Chapter 2 45 min, Chapter 3 30 min, Chapter 4 25 min, Chapter 5 35 min, Chapter 6 30 min, Chapter 7 20 min.
  • Accounts: check before the day that every participant has a Copilot plan that includes Copilot CLI and code review, and that Codespaces is allowed for their account or organisation.
  • Cost awareness: the issue-triage run in the real run used about 13 GitHub AI Credits. Copilot Fusion, Copilot code review and AI scan also use AI credits; code scanning, secret scanning, push protection and Dependabot are free on public repositories.
  • Roles: one participant can play every role, or split the room: one person files Lina's issue, one plays Raka and reviews the guardrails.
  • Public by design: everything uses fictional Contoso data. Never use real customer names or secrets in the workshop repository.

Clean-up

  1. Stop or delete the codespace: Code → Codespaces → … → Stop codespace or Delete.
  2. Disable the agentic workflow if you keep the repository public: Actions → Issue triage → … → Disable workflow.
  3. Keep or archive the repository as your reference.
