Review the pull request with Copilot code review

Ask Copilot to review the Careers pull request, act on its comments, make Copilot review automatic for every pull request and ship the page.

Real run in progress. Chapter 4 is written from GitHub Docs and is being run end to end in the demo repository now. Annotated screenshots from that run replace the placeholders below in the next update.
Before the merge

Daniel: “Ask Copilot to review it first. Then you review what Copilot found. And make it automatic, I don't want to remember this every time.”

4.1

Request a review from Copilot

On the pull request, open Reviewers and select Copilot. The review usually arrives within a few minutes.

Figure 4.1 · Real-run screenshot coming in the next update.
Developer mode

See Using Copilot code review for the other ways to ask for a review.

Why it matters: Copilot code review reads the diff in the context of the repository and of .github/copilot-instructions.md.

4.2

Read Copilot's review

Copilot leaves a summary and inline comments, often with a suggested change you can commit directly. By default it comments rather than approving, so it never blocks a merge on its own.

Figure 4.2 · Real-run screenshot coming in the next update.
4.3

Act on the comments

For each comment, either select Commit suggestion, ask Copilot CLI in the codespace to address it, or resolve it with a reply explaining why not. Then re-request the review.

Figure 4.3 · Real-run screenshot coming in the next update.

Why it matters: You stay accountable for what is merged. Copilot is a fast, consistent reviewer, not the approver of record.

4.4

Make Copilot review automatic with a ruleset

  1. Open Settings → Rules → Rulesets → New ruleset → New branch ruleset.
  2. Name it main-review, set Enforcement status to Active and target the default branch.
  3. Tick Automatically request Copilot code review and select Create.
Figure 4.4 · Real-run screenshot coming in the next update.
Developer mode

See Configuring automatic code review by Copilot.

Why it matters: Every future pull request to main gets a Copilot review without anyone remembering to ask.

4.5

Merge and ship the Careers page

Merge the pull request. Issue #1 closes automatically, the Pages workflow deploys and the Careers page is live.
