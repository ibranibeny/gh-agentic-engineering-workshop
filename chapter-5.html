Chapter 5 · about 35 minutes

Code security: CodeQL, Copilot Autofix and push protection

Turn on CodeQL code scanning, find the cross-site scripting bug hidden in the legacy newsroom search, fix it with Copilot Autofix and watch push protection stop a secret before it lands.

Real run in progress. Chapter 5 is written from GitHub Docs and is being run end to end in the demo repository now. Annotated screenshots from that run replace the placeholders below in the next update.
Raka's office

Raka: “Copilot reviewed the new code. Fine. Who reviewed the old code from the agency? Nobody. Scan everything.”

5.1

Turn on CodeQL default setup

  1. Open Settings → Advanced Security.
  2. Under Code scanning, find CodeQL analysis, select Set up → Default.
  3. Review the languages (JavaScript/TypeScript and GitHub Actions) and select Enable CodeQL.
Copy & pasteAll commands
>_Your terminal (GitHub CLI)Optional
gh api -X PATCH "repos/{owner}/{repo}/code-scanning/default-setup" -f state=configured
gh api "repos/{owner}/{repo}/code-scanning/default-setup" --jq '{state, languages}'

Optional. It changes a repository setting, which the codespace's built-in token cannot do, so run it where you signed in with your own account (how).

5.2

Find the vulnerability

When the first analysis finishes, open Security and quality → Code scanning. CodeQL reports a cross-site scripting alert in src/assets/js/news-search.js: the q URL parameter flows into innerHTML.

Copy & pasteAll commands
>_Your terminal (GitHub CLI)Optional
gh api "repos/{owner}/{repo}/code-scanning/alerts?state=open" \
  --jq '.[] | [.number, .rule.id, .most_recent_instance.location.path] | @tsv'

Optional. It reads security alerts, which the codespace's built-in token cannot do, so run it where you signed in with your own account (how). Expected: a cross-site scripting alert in src/assets/js/news-search.js.

Figure 5.3 · Real-run screenshot coming in the next update.
Developer mode

The vulnerable lines from the legacy widget:

document.getElementById('search-summary').innerHTML =
    matches + ' result(s) for <strong>' + query + '</strong>';

Why it matters: Anyone could craft a newsroom link that runs script in a visitor's browser. CodeQL shows the full path from source to sink.

5.3

Generate a fix with Copilot Autofix

On the alert, select Generate fix. Copilot Autofix explains the problem and proposes a patch. Review it, then create a pull request with the fix.

Copy & pasteAll commands
>_Your terminal (GitHub CLI)Optional · REST API
ALERT=$(gh api "repos/{owner}/{repo}/code-scanning/alerts?state=open" \
  --jq '[.[] | select(.most_recent_instance.location.path == "src/assets/js/news-search.js")][0].number')
echo "Alert: $ALERT"
gh api -X POST "repos/{owner}/{repo}/code-scanning/alerts/$ALERT/autofix"
sleep 30
gh api "repos/{owner}/{repo}/code-scanning/alerts/$ALERT/autofix" --jq '.status, .description'

Asks Copilot Autofix for a fix. Re-run the last line until the status is success.

>_Your terminal (GitHub CLI)Optional · REST API
gh api -X POST "repos/{owner}/{repo}/git/refs" -f ref=refs/heads/fix/newsroom-xss \
  -f sha="$(gh api "repos/{owner}/{repo}/git/ref/heads/main" --jq .object.sha)"
gh api -X POST "repos/{owner}/{repo}/code-scanning/alerts/$ALERT/autofix/commits" \
  -f target_ref=refs/heads/fix/newsroom-xss -f message="Fix XSS in newsroom search (Copilot Autofix)"
gh pr create --base main --head fix/newsroom-xss \
  --title "Fix XSS in newsroom search" --body "Copilot Autofix for code scanning alert #$ALERT"

Commits the fix to a new branch and opens the pull request. Same terminal, so $ALERT is still set.

5.4

Merge the fix and close the alert

Merge the pull request. The next CodeQL analysis on main confirms the fix and closes the alert.

Copy & pasteAll commands
>_Your terminal (GitHub CLI)Optional
gh pr merge fix/newsroom-xss --squash --delete-branch
gh api "repos/{owner}/{repo}/code-scanning/alerts?state=fixed" --jq '.[] | [.number, .rule.id, .state] | @tsv'

Only if you used the REST commands in 5.3; otherwise merge the Autofix pull request in the browser. The alert shows as fixed after the next analysis on main.

5.5

See push protection stop a secret

Use GitHub's official dummy token (it is not a real credential) to see push protection in action:

  1. Open the GitHub Docs tutorial Storing your secrets safely and copy the dummy token it provides for this exercise.
  2. In your repository select Add file → Create new file and name it secret-test.txt.
  3. Paste the dummy token and select Commit changes.
  4. GitHub blocks the commit and explains why. Select Cancel: do not bypass.
Why this guide does not print the token. When we published this guide, push protection blocked the upload because the Chapter 5 page contained that dummy token, even though the upload went through the API rather than git push. That is the same protection you are about to see.
Copy & pasteAll commands
>_Codespace terminalOptional · command line
read -rsp "Paste the dummy token from the GitHub Docs tutorial, then press Enter: " TOKEN; echo
git switch -c test/push-protection
printf '%s\n' "$TOKEN" > secret-test.txt
git add secret-test.txt
git commit -m "Test push protection"
git push -u origin test/push-protection

Expected: GitHub rejects the push because it contains a secret. Do not bypass.

>_Codespace terminalClean up
git switch main
git branch -D test/push-protection
unset TOKEN

Deletes the test branch and its blocked commit. Nothing reached GitHub.

Figure 5.7 · Real-run screenshot coming in the next update.
Developer mode

Push protection for users is on by default and stops you pushing secrets to public repositories. GitHub Docs lists the surfaces it covers: pushes from the command line, commits made in the GitHub UI, file uploads and REST API requests. In our run it also blocked a commit made through the GraphQL API. See Push protection.

Why it matters: Secrets are stopped before they reach Git history, where they are expensive to remove and must be rotated.

Checkpoint

Done when CodeQL is enabled, the XSS alert is fixed and closed, and you have seen push protection block the dummy token.
